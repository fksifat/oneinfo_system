# Original Essential artwork — SVG exports

Converted from the four supplied EPS files using Ghostscript pdfwrite (EPSCrop)
and PyMuPDF SVG export with text converted to paths. No design was redrawn.
Dimensions preserve the EPS artwork bounds, including its print bleed.

All four SVG files contain vector paths and zero embedded raster images.
EPS/SVG renders were compared at 300 dpi: mean RGB differences were under
2.3 levels out of 255 (mostly edge antialiasing). Colour is converted to RGB
for SVG display; these are web/editing exports, not replacement CMYK print masters.

The website has not been assigned these SVGs automatically. To use them manually,
paste /assets/essential-svg/<filename>.svg into an Image item in the admin gallery.
Those optional URLs are bundled with the storefront.
