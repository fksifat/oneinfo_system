Oneinfo কার্ড অ্যাক্টিভেট করুন

শুরু করার আগে কার্ড ও প্যাকেটে দেওয়া Secret code কাছে রাখুন।

  1. কার্ড ট্যাপ করুন বা QR স্ক্যান করুন

    ফোনে NFC চালু করে কার্ডটি ফোনের পেছনে ধরুন। অথবা ক্যামেরা দিয়ে কার্ডে ছাপানো QR কোড স্ক্যান করে লিংকটি খুলুন।

  2. Secret code লিখুন

    Activate your card স্ক্রিনে প্যাকেটে দেওয়া কোডটি লিখে Activate & continue চাপুন।

  3. প্রোফাইল সেভ করুন

    আপনার নাম ও যোগাযোগের তথ্য দিয়ে Create account & save profile চাপুন। আগে থেকেই অ্যাকাউন্ট থাকলে Sign in করে প্রোফাইল সেভ করুন।

  4. কার্ডটি আবার পরীক্ষা করুন

    আবার ট্যাপ বা স্ক্যান করে দেখুন আপনার পাবলিক প্রোফাইল খুলছে কি না।

প্রতিটি Secret code একবার ব্যবহার করা যায়। কোডটি নিজের কাছে রাখুন।
